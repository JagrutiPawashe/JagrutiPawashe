## 🏥 Healthcare Mediclaim Coverage Assessment

An NLP-based system developed to assess whether medical procedures or treatments are covered under healthcare insurance policies.

The project uses **BERT-based Named Entity Recognition and classification logic** to identify relevant medical information and categorize coverage as:

* Covered
* Not Covered
* Conditional
* Vague

The solution was designed for a restricted enterprise environment with privacy and secure-processing requirements.

**Tech:** Python • BERT • NLP • NER • Machine Learning
